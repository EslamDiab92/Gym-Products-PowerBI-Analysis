# Gym Products Sales Analysis – Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze sales performance
using data from 8 Excel files.

The project covers revenue, profit, customers, returns, products,
time trends, and geographical performance.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Excel
- ETL

## Project Workflow

Excel Files
→ Power Query ETL
→ Data Transformation
→ Data Modeling
→ DAX Measures
→ Interactive Power BI Dashboard

## Dashboard Pages

- Overview
- Revenue Analysis
- Customer Analysis
- Returns Analysis
- Time Analysis
- Product Analysis
- Location Analysis

## Key Features

- Interactive slicers
- Dynamic titles
- Year-over-Year analysis
- Time intelligence
- Drill-through analysis
- KPI cards
- Interactive navigation
- Fact & Dimension data model

## Project Objective

The objective of this project was to transform raw data into
an interactive BI solution that helps users understand sales
performance and customer behavior.
